# Collatz's Conjecture
## Project's Description
A Python program held in it's own Python Virtual Enviroment. A practice to test these enviroments and how to treat Python dependencies. A really fun and interesting mathematical conjecture was chosen for this project.
### About the code...
The script will ask for numbers...
1. The quantity of numbers that are going to be computed
2. The number in _int_ format.

The **output** is a plotted graph, following the Collatz's conjecture.

> *(try out plotting numbers 27 and 195)*

## How to set the enviroment
```bash
cd scripts/
./enviromentCreator.sh
```

## How to execute the script
```bash
source env1/bin/activate
python3 Collatz.py
```
